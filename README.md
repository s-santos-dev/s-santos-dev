# 🚀 Projetos em destaque

## 🚰 PIPA Inteligente

Solução desenvolvida durante a **Maratona do Piauí para o Mundo 2026** para tornar operações de distribuição de água por caminhões-pipa mais eficientes, inteligentes e rastreáveis.

O sistema combina **Inteligência Artificial, otimização logística e IoT** para analisar a necessidade das comunidades, priorizar regiões com maior urgência de abastecimento, otimizar rotas e manter registros digitais das operações realizadas.

A arquitetura utiliza **Machine Learning** para apoiar a priorização da demanda, algoritmos de **TSP/VRP** para otimização logística e dispositivos baseados em **ESP32** para monitoramento de reservatórios.

**Principais recursos:** priorização inteligente • otimização de rotas • monitoramento de reservatórios • rastreabilidade de entregas • histórico operacional

`Python` `Machine Learning` `IoT` `ESP32` `TSP/VRP` `Geolocalização`

## 💧 Aquífero Vivo

Plataforma de inteligência voltada à análise de **águas subterrâneas**, criada para transformar dados dispersos de poços e séries históricas em informações geográficas e indicadores úteis para investigação e segurança hídrica.

O sistema organiza informações de poços em um **mapa geográfico interativo**, permitindo analisar setores, acompanhar históricos de medições, identificar alterações relevantes e destacar regiões que merecem investigação prioritária.

A arquitetura utiliza uma **API em FastAPI**, banco de dados **PostgreSQL**, processamento de séries temporais e dados geoespaciais. A camada analítica é preparada para aplicar modelos de **Machine Learning** na identificação de padrões, agrupamento de regiões semelhantes e estimativa de vulnerabilidade.

**Principais recursos:** mapa de poços • análise por setores • séries históricas • alertas • análise geoespacial • identificação de áreas vulneráveis

`Python` `FastAPI` `PostgreSQL` `Machine Learning` `Geoprocessamento` `APIs`

## 🫀 VitaPulse

Sistema de **monitoramento inteligente de saúde** desenvolvido para integrar coleta de sinais vitais, processamento de dados e geração de alertas em situações que exigem atenção.

A solução conecta dispositivos de monitoramento a uma plataforma capaz de acompanhar informações como **frequência cardíaca, SpO₂ e temperatura**, além de trabalhar com eventos críticos, como detecção de queda.

A arquitetura combina dispositivos baseados em **ESP32**, uma **API desenvolvida com FastAPI** e aplicações responsáveis pela visualização e acompanhamento das informações. O backend centraliza os dados recebidos e disponibiliza os recursos necessários para integração entre dispositivos, usuários e interfaces do sistema.

**Principais recursos:** monitoramento de sinais vitais • detecção de eventos críticos • alertas • acompanhamento de dados • integração IoT • API centralizada

`Python` `FastAPI` `ESP32` `IoT` `APIs` `Monitoramento`
